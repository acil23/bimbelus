# BimbelUs

Production-oriented full-stack web application for BimbelUs,
an educational tutoring business.

## Project Status

Development

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma
- Zod

## Architecture

The application uses a Modular Monolith architecture.

## Scope

The current production scope is Level 1:

- Company profile
- Programs
- Tutors
- Student achievements
- Contact information
- Admin CMS

## Documentation

Detailed system and technical design are maintained
in the BimbelUs SDD v1.1.
